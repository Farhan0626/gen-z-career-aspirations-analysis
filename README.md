# Gen Z Career Aspirations – Data Analytics Project

## Project Overview

This project focuses on understanding the career aspirations, preferences, salary expectations, and workplace priorities of Generation Z through data analytics.

The objective is to explore survey data, identify meaningful patterns, and present findings through data analysis, visualizations, and interactive dashboards.

## Tools & Technologies

- Microsoft Excel
- SQL Server Management Studio (SSMS)
- Microsoft Power BI

## Project Workflow

### 1. Data Collection

Worked with survey data related to Gen Z career aspirations, career preferences, and workplace priorities.

### 2. Data Cleaning

Cleaned and standardized the dataset by handling inconsistencies, formatting columns, and preparing the data for analysis.

### 3. Exploratory Data Analysis (EDA)

Explored the dataset to understand career preferences, salary expectations, benefits, and other important trends.

### 4. SQL Analysis

Used SQL queries to retrieve, filter, group, and analyze data to answer key analytical questions.

### 5. Excel Dashboard

Created an Excel dashboard to present important metrics, comparisons, and survey insights through charts and visualizations.

### 6. Power BI Dashboard

Developed interactive Power BI dashboards covering:
- Manager Aspirations
- Mission Aspirations

### 7. Insights & Reporting

Presented key findings through charts, dashboards, and analytical summaries.

## Key Skills Demonstrated

- Data Cleaning and Standardization
- Exploratory Data Analysis (EDA)
- SQL Querying
- Data Visualization
- Excel Dashboard Development
- Power BI Reporting
- Analytical Thinking
- Business Insights

## Project Files

The repository contains:

## Conclusion

This project demonstrates a practical data analytics workflow, from preparing survey data and performing analysis to developing interactive dashboards and presenting meaningful insights.

It highlights the use of Excel, SQL, and Power BI to transform data into clear and useful information.
