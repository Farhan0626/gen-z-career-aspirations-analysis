# Gen Z Career Aspirations – Data Analytics Project

## Project Overview

This project focuses on understanding the career aspirations, preferences, salary expectations, and workplace priorities of Generation Z through data analytics.

The objective is to explore survey data, identify meaningful patterns, and present findings through data analysis and interactive dashboards.

## Tools & Technologies

- Microsoft Excel
- SQL Server Management Studio (SSMS)
- Power BI

## Project Workflow

### 1. Data Collection
Worked with survey data related to Gen Z career aspirations and workplace preferences.

### 2. Data Cleaning
Cleaned and standardized the dataset by handling inconsistencies, formatting columns, and preparing data for analysis.

### 3. Exploratory Data Analysis (EDA)
Explored the dataset to understand career preferences, salary expectations, benefits, and other important trends.

### 4. SQL Analysis
Used SQL queries to retrieve, filter, group, and analyze data to answer key business questions.

### 5. Excel Dashboard
Created an Excel dashboard to present important metrics, comparisons, and survey insights.

### 6. Power BI Dashboard
Developed interactive Power BI dashboards to visualize career aspirations and workplace-related findings.

### 7. Insights & Reporting
Summarized key findings through charts, dashboards, and a final project presentation.

## Key Skills Demonstrated

- SQL Querying
- Data Visualization
- Excel Dashboard Development
- Power BI Reporting
- Analytical Thinking
